# KDE Feature Distribution Plotter – Synthetic Datasets (CTGAN / TVAE)

This script generates **Kernel Density Estimation (KDE)** plots for each numeric feature across **synthetic datasets** produced by **CTGAN** or **TVAE** models. It is primarily used to visually analyze and compare how synthetic data distributions differ between models and attack classes.

---

## Overview

Each synthetic dataset folder contains multiple CSV files — each corresponding to a specific label (e.g., `BENIGN`, `DoS Hulk`, `FTP-BruteForce`, etc.). The script merges all available CSVs within each folder, extracts numeric columns, and creates KDE distribution plots for every feature across all labels.

The plots are saved as `.png` files under the defined output directory, grouped by dataset year or type.

Use this tool to:

* Compare **feature distributions** between synthetic data generated by **CTGAN** and **TVAE**.
* Assess **data quality** and **feature diversity** across synthetic samples.
* Identify overlaps or separations between different attack categories.

## Example Configuration

###  TVAE Example

```python
INPUT_FOLDERS = {
    "2017": "/datasets/synthetics/oversampling_TVAE/2017",
    "2018": "/datasets/synthetics/oversampling_TVAE/2018",
    "for_all": "/datasets/synthetics/oversampling_TVAE/for_all"
}

OUTPUT_FOLDER = "/data_distribution_kde_plots/synthetics/tvae"
```

###  CTGAN Example

```python
INPUT_FOLDERS = {
    "2017": "/datasets/synthetics/predict_CTGAN/2017",
    "2018": "/datasets/synthetics/predict_CTGAN/2018",
    "for_all": "/datasets/synthetics/predict_CTGAN/for_all"
}

OUTPUT_FOLDER = "/data_distribution_kde_plots/synthetics/ctgan"
```

##  Usage

1. Open the script `kde_plots_synthetics.py`.
2. Update the configuration section at the top:

   ```python
   INPUT_FOLDERS = { ... }
   OUTPUT_FOLDER = "..."
   ```
3. Run the script:

   ```bash
   python kde_plots_synthetics.py
   ```
4. The KDE plots will be generated for all numeric features and saved under the defined output directory.

---

##  Notes

* Non-numeric columns such as `Dst Port` and `Protocol` are automatically ignored.
* Each figure corresponds to one numeric feature plotted across all available labels.
* The `BINS` variable (default = `10`) controls the number of intervals along the X-axis.
* Each subplot title contains the respective label name.
